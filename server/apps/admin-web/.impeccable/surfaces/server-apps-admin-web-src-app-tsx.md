# Surface brief: AudioReader operator console

## Scope and visitor mode

Operate. Whole web surface at `server/apps/admin-web` (Cloudflare Pages). Not a native Settings page.

## Audience, job, constraints

Operators keep hosted Qwen, storage, Turnstile, users, policies, jobs, cache, blocked attempts, metrics, and audit healthy without editing Worker files. Sign-in is product email OTP (Turnstile only after challenge) or a pasted admin JWT. Secrets are never echoed. GCS needs a GCP billing account; without it storage stays on Supabase.

## Chosen direction

Paper Desk adapted for Operate. Code-led. User pinned the established native world, health-first viewport, and code-led path. Seed not rolled.

## Memorable moment

Live gold health pips in the top bar, a lined service ledger, then a grouped runtime form whose terracotta Save writes `operator_settings` without a redeploy. Change reason lives at the foot of the destination rail and authorizes every mutation.
